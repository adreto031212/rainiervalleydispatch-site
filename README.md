# rainiervalleydispatch.com

Static landing site for the Rainier Valley Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py rainiervalley` in the ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `rainiervalley-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
